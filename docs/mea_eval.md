# MEA 后验解码（`--mea`）：实现与 simTest 评测

2026-11-07。方案见 `docs/mea_plan.md`；框架是 `--realign`（`docs/realign_plan.md`、`docs/realign_ksw2_eval.md`）。代码尚未提交（基于 a9897c6）。

## 1. 实现

- `--mea=<λ倍数>,<θ>`，必须与 `--realign` 一起给。在 `--realign` 的每一段里：
  1. 先做 Viterbi（含加宽）；
  2. 在同一带内做前向-后向，路径权重 exp(λ·S)，λ = 倍数 × λ_KA（HoxD55 均匀背景 λ_KA ≈ 0.00889）；
  3. 最大化 Σ_匹配列 (后验 − θ)（gap 列记 0），得到 MEA 路径；
  4. MEA 路径碰到带边时加宽重算。
- 数值：对角线列与 gap 列按 smax 平移（所有路径同乘一个常数），前向、后向按行缩放。以下情况保留 Viterbi 路径（`mea fallback`）：
  - 矩阵超过 2^26 格；
  - 某行全部下溢；
  - 前向与后向的总权重相差超过 1e-6。
- 文件：`src/realign.c`（`mea_*`）、`src/realign.h`、`src/realign_test.c`、`src/lastz.c`（选项、依赖检查、`--help`）。

## 2. 验证

### 2.1 本地（OrbStack ubuntu VM，gcc 11.4，`-Werror`）

- **构建**：`lastz`、`lastz_D`、`realign_test` 0 警告。统计版（`-Dcollect_stats`，不加 `-Werror`）的 5 条警告都在原有文件里（`gapped_extend.c` 2 条、`pos_table.c` 2 条、`quantum.c` 1 条）。
- **`realign_test`**：默认 26,784 项、9000 轮 80,728 项检查，0 失败。新增的测试：
  - (5) **穷举对照**：长度 0–6，HoxD55/HoxD70，4 组 gap，λ 倍数 0.5–5，θ 0–0.8，带宽随机，1001 例。
    - 枚举带内全部全局路径（最多 8,989 条）求精确后验，与 `mea_posteriors` 的最大误差 5.7e-14（9000 轮时 8.2e-14）；
    - MEA 目标值与穷举最优相同；路径消耗两侧、不出带。
  - (6) **λ 极限**：λ×30、θ=0.5 时，MEA 的对齐碱基对集合与 Viterbi 相同。默认轮数下 122/122 例一致，9000 轮下 346/347（剩下 1 例是近平局）。左右对齐的 Viterbi 不同的例子视为平局，跳过。
  - (6b) **MEA 平局方向**：A 对 AA、AA 对 A，θ=0.8，right/left 各一例。
  - (7) **`realign_aligns` 开 MEA 的整体性质**：301 条随机比对。首尾坐标、两侧长度不变，输出分 = `score_alignment`，fallback 为 0；MEA 改变了 642/651 段的路径。
- **变异检验**：在以下 6 处各改一处，测试都报错：
  - X 开 gap 用 ge；
  - 前向缩放不累计；
  - B_M 下行用 ge；
  - θ 符号；
  - Y 允许由 Y 开；
  - MEA 平局方向。

  另有一个"后向带外哨兵不清零"的变异没被抓到，查明是那几行本来就多余：带单调移动，行数组在开头整体清零。已删去，`mea_posteriors` 头注释写明了原因。
- **`base_tests`**：19 项 SUCCESS。
- **回归**：不加 `--mea` 时，37 组选项与 a9897c6 逐字节一致（stdout、stderr、退出码、nlchain 段表）。清单是 `nlchain_progress.md` §11.2 的 24 + 8 组（`[multiple]` 的 4 组改用 maf 输出），另加以下 5 组：
  - G3a + `--gap=500,30`；
  - `--realign=400,8`（maf）；
  - G3a + `--realign=400,8`；
  - `--realign=400,8,left`（general）；
  - `--realign=400,30`（sam）。
- **报错用例**（8 个）：
  - 不带 `--realign`；
  - 少写 θ；
  - λ 倍数为 0 或负；
  - θ=1 或负；
  - 重复给出；
  - 非数字。
- **冒烟**：pseudocat/pseudopig 与 aglobin（G3a + `--gap=500,30`）上加 `--realign=400,8 --mea=…`（4 组参数加左对齐）：
  - 块数、首尾坐标、去 gap 序列都与只加 `--realign` 时相同；
  - lav/axt/general/sam/cigar 都能正常输出；
  - `lastz_D` 的比对文本与 `lastz` 一致。
- **λ×0.5 的现象**：冒烟中 λ 倍数为 0.5、θ=0.5 时，对齐碱基对几乎全被去掉（pseudocat 19,356 → 91，aglobin 20,320 → 109）。原因是温度太高，路径分布"熔化"，后验普遍低于 0.5。所以网格没有放 0.5。

## 4. 结论

1. **MEA 提高了 F**。最好的两组相对当前推荐配置：
   - `--mea=2,0.5`：F_np +0.0139、F_anc +0.0122；
   - `--mea=1.5,0.5`：F_np +0.0161、F_anc +0.0109。

   10/10 个物种对两项都提高，越远缘提高越多（Mouse-Rat +0.001–0.002，Cow-Rat +0.019）。这一收益与 `--realign` 本身的收益（F_np +0.015）同量级，两者叠加。
2. **收益分两部分，大头不是"改对"**（§3.3）：
   - **改对**（θ=0，只按后验选路径）：TP +0.0070（约 56 万对），错位 ≤100 −0.0063，FP −0.0042，未比对基本不变。错位碱基对被挪到真值位置上，recall 和 precision 同时提高，mafComparator F_np +0.006。
   - **改成不比对**（θ 从 0 升到 0.5）：TP −0.0112、FP −0.0399、未比对 +0.0339。后验低的碱基对多数是错位的，去掉它们，每对少一个 FP，漏检从"错位"类转到"未比对"类。这部分是用 recall 换 precision，在 F 上划算。
   - 所以 `--mea=2,0.5` 的错位 ≤100 漏检虽然减少 0.029（占真值），但大部分是变成了未比对，真正改对的约 0.007。3e 的判断仍然成立：多数错位按打分模型本来就是最优，后验解码也只能识别出"不确定"，不能把它们改对。
3. **λ 与 θ 的最优点在一条平坦的脊线上**：λ 越小，最优 θ 越小。脊线上 F 的差别在 0.002 以内。
   - λ×1（即 λ_KA）不行：后验普遍偏低，θ 稍大就大量丢掉正确的碱基对。λ_KA 对应的温度对这里的全局段比对来说太高。
   - λ 太大（×3）则退回接近 Viterbi，收益减半。
4. **推荐 `--mea=2,0.5`**：
   - F_anc 最高，F_np 只比 1.5,0.5 低 0.002；
   - 在 θ ∈ [0.5, 0.7] 内 F_np 都 ≥ 0.779，对 θ 不敏感；而 λ×1.5 时 θ 从 0.5 到 0.7 掉 0.011，离 λ×1 的崩塌区更近。
   - simTest 是调参集，选更稳的一组。
5. **开销**：总时间 +13.4%，fallback 为 0。

## 5. 未解决 / 风险

- 只在 simTest（调参集）、HoxD55、当前推荐配置上测过。
- θ 的收益来自"不确定就不比对"。下游如果更看重覆盖度（recall）而不是 precision，应取较小的 θ（θ=0 也有 F_np +0.006）。
- 还没有把推荐写进 `nlchain_design.md` 的推荐配置。
- λ 与 θ 的最优值依赖打分矩阵（λ 以 λ_KA 为单位，换矩阵时应大致可迁移，但没有验证）。
- MEA 路径不考虑 gap 罚分，gap 列数增加（比对列数 +3.7%）；输出分数仍按 lastz 打分重算，会比 Viterbi 路径低。下游如果按分数过滤，需要注意。
- 前向-后向是标量 double 实现，没有向量化；重比对阶段耗时翻倍。

## 6. 下一步

1. 决定是否采纳 `--mea=2,0.5` 作为推荐配置，写入 `nlchain_design.md` §8.3 与 `--help` 示例。
2. 在调参集之外的数据上复核（例如 simHuman–simMouse 全量），确认 λ×2、θ=0.5 不是过拟合 simTest。
3. 如果要提高"改对"的比例，需要改模型本身，而不是改解码：例如按局部一致率调整 λ，或用 Baum-Welch 估计 gap 参数。
4. 性能：前向-后向向量化（float/SIMD），或只在 Viterbi 路径附近的窄带里做。
